# Sennheiser EQ Presets

A small collection of headphone equalization presets for use with EasyEffects on Linux.

## Supported Headphones

| Model | Preset |
|---|---|
| Sennheiser HD 599 | `599-eq` |
| Sennheiser HD 600 | `600-eq` |

## Usage

Download the corresponding EQ preset and import it into EasyEffects using the equalizer import functionality.
